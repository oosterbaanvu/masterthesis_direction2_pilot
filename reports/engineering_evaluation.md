# Engineering evaluation

The artifact is an executable Python package (`dqp`) with pinned dependencies/lockfile, source-specific acquisition, raw-data integrity checks, a nine-kind safe rule language, a read-only local SQL connector, qualification, an opt-in provider, a stateful governance service and experimental scorers.

`results/service_demo.json` is measured service evidence: full scans of ten acquired regular/pair sources, one development SEC table and three actual ordered bank delivery batches. It records batch-level findings, event count, monitoring-profile count and exception-workflow execution. A handcrafted clean fixture exercises the qualification-to-approval path before operational missing-token monitoring. That is explicitly a lifecycle demonstration, not scientific proof that a rule is valid on real source data. No AI proposal is automatically activated.

The test suite exercises numeric normalization, malformed rules, SQL parameter/identifier isolation, prohibited write/extension operations, read-only external SQL, deduplication, qualification invariance, official/corrected metrics, grouped splits, multiline CSVs, numerical-equivalence labels, unchanged numeric injections, lifecycle/monitoring, paid-call authorization, budget/call reservation, caching and failed-call resume. HTTP provider responses in tests are mocked and never reported as model research output. A CLI integration test executes a CSV scan through the installed module and checks a real finding.

Actual enforcement: DSL allowlist, safe compiler, SQLite read-only authorizer, progress-handler timeouts, source file permission bits, hash verification, explicit activation and environment-only credentials. Simulated controls: reviewer identity strings, separation of duties, audit durability and approval authority. No authentication or tamper-proof storage is claimed. Source values in the ignored local governance database need a retention/redaction policy before sensitive-data use.

Limitations: generic missing-token scans do not infer mandatory business fields; no broad contradiction/subsumption solver; whitespace is the qualification perturbation, not an exhaustive semantic robustness test; an evidence string is only a citation to review; statistical monitoring is descriptive; no live provider inference or enterprise connector was exercised. The SEC accounting sensitivity documents an ordinary formatting failure of the conservative lexical parser rather than hiding it. These limits do not prevent local development, testing and experimental scoring.

Final verification: **36 passed, zero failed/skipped**; Ruff passed; repeating the setup preserved the frozen result hashes; the complete documented reproduction produced matching scientific artifacts in a new output directory. Configuration save/readback confirms installation and startup instructions plus required network-domain additions. Publication and new-cloud-task restoration were not performed.
