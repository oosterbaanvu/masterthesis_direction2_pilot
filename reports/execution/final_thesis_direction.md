# Recommended MSc AI thesis direction

**CONDITIONAL GO for a narrow empirical reliability study. NO-GO for the broad claim of a new generic rule-generation/qualification algorithm.** Real local inference and independent post-selection scoring now work. The strongest remaining uncertainty is scientific: independent rule meaning and a distinct contribution relative to close prior work.

Provisional question:

> Under documented and undocumented changes in source contracts, units and scope, when does label-free qualification of fixed LLM-generated checks discard useful incremental detections or promote unjustified controls, relative to technical filtering, documentary matching and a development-label-assisted coverage reference?

The AI component is actual model synthesis of executable checks, followed by an empirical study of selective acceptance and abstention. Conventional controls, code safety and the lifecycle service support the experiment. They are not the claimed AI novelty. The primary contribution would be an independently adjudicated failure-boundary study, including negative results and a reproducible artifact.

The current evidence separates possible causes. The 7B model is computationally viable; poor API syntax in the original smoke is an observed implementation issue. Modern syntax guidance improves executability but does not settle meaning. Hospital/Beers references allow conditional detection scoring, while missing semantic judgments prevent claims about real validity. C's conservative documentary requirement limits acceptance by construction; lost coverage is evidence about this baseline, not all label-free methods. Zero additional Beers hits can reflect candidate quality, baseline coverage and benchmark composition; one dataset does not identify a universal absence of benefit. Closest-work overlap remains unresolved.

## Nine-month bounded programme and stop rules

1. Month 1: supervisor confirms the precise gap after full closest-paper review; secure two competent reviewers and a rights-cleared source portfolio. Stop/reframe if no distinct question or feasible semantic labels.
2. Months 2–3: freeze generated candidates, controls, independent source groups, documentation-change conditions and review criteria. Use a development-only model/threshold pilot; reserve a new source holdout. Keep this execution exploratory.
3. Months 4–5: run the accepted comparisons and independent blinded rule/violation reviews. Add one stronger free model only if compute and the hypothesis justify it; no unapproved paid service.
4. Month 6: assess robustness to units, missing conventions, temporal scope and explicitly supported representation changes. Separate natural/reference/injection outcomes and report abstention versus missed incremental value.
5. Month 7: reproduce on reserved source groups, estimate uncertainty at the appropriate source/entity unit and document semantic cannot-judge cases. Avoid cell-level pseudo-replication.
6. Months 8–9: connect the frozen research artifact to the monitoring service, consolidate reproducibility and write the thesis. A negative result is acceptable if independently valid and sufficiently generalizable; a missing evaluation is not.

Supervisor decisions concern contribution scope, closest-paper adequacy, semantic review/ethics and rights, the held-out source design, the minimum meaningful effect and attainable source-level power. This is academic approval of a concrete design; it is not a request for another ordinary software implementation permission.
