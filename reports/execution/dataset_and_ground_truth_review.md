# Dataset and ground-truth review

The primary real-data portfolio is UCI Credit, Bank Marketing, White Wine, Hospital and Beers. The journal source is a sixth, self-authored engineering scenario. These sources do not provide a common semantic-error gold standard. Scores are kept separate by source, corruption family, baseline strength and localization unit.

| Source | Actual new evaluation | Defensible target | Principal limitation |
|---|---|---|---|
| UCI Credit | Genuine generated rules, 512 development and 512 exploratory rows, duplicate-feature-group separation | Controlled deletion and type/domain violations; separately, recovery of scale/swap alterations | Classification outcomes are excluded; they are not DQ labels. Unaltered rows can already contain unknown errors. A plausible changed value need not be invalid |
| UCI Bank Marketing | Same grouped, capped design | Same separate controlled populations | Source conventions and unknown codes require scope; frequent values do not certify a business constraint |
| UCI White Wine | Same grouped, capped design | Same separate controlled populations | Scientific measurements have distributions, not automatically hard validity bounds; guessed ranges need independent justification |
| Hospital, pinned Raha/Jung reference pairs | Schema-only real generation, provider-disjoint development/exploratory partition | Conditional agreement with published reference discrepancies | 155 test rows from only seven providers; text-valued score/sample fields and representation differences make blanket numeric claims unsafe |
| Beers, pinned Raha/Jung reference pairs | Schema-only real generation, brewery-disjoint partition | Conditional agreement with published reference discrepancies | 401 test rows, 95 breweries; imperfect reference completeness and numeric unit conventions. Off-reference alerts are not independently proven errors or false positives |
| Synthetic balanced journals | Real generated rules, 256 separate DEV and TEST journal IDs | Stipulated same-currency, integer-cent equality and controlled changes | No natural financial population, external validity or independent domain adjudication |

Source files and their hashes, split hashes, entity counts and zero group overlap are recorded in each `results/execution/evaluation/*.json`. UCI grouping hashes feature values before modification and excludes the row identifier. Published benchmark grouping uses the reference provider/brewery identity solely as split metadata; reference values are not given to the model or qualifier. B alone receives development error labels. This split-design use of reference identity must not be described as wholly reference-free data preparation.

The 60/20/remainder partition uses fixed hash salts; the exploratory partition is the held-out evaluation in this execution. It is not a new confirmatory test: these public datasets and earlier phases were already inspected. No claim of a perfectly preregistered study is made. Strong historical envelopes are fitted on development rows only. Per-family injections choose at most 24 rows, count actual changed cells and use different development/test seeds. Missingness is a controlled deletion, invalid types/codes are operational violations, and gross scale/plausible swaps are explicitly **alteration recovery**, not automatically genuine DQ errors. Off-injection source alerts remain unadjudicated. Both raw batch agreement and per-rule before/after new-alert diagnostics are available; these answer different questions.

The published-cell track includes only single-column candidates whose flagged cells can be localized without attributing blame to every participant in a relation. The separate row track includes relational rules. Its row recall must not be compared numerically with cell recall. Normalization-equivalent reference changes are excluded using the preserved adapter, not a new model-dependent cleaning pass.

Published-source controls are limited: Hospital's two configurations are both generic missing-token screening; Beers' stronger configuration adds lexical numeric ABV/IBU checks. Neither is a complete independently justified business suite. The `strong` name is relative and cannot substantiate a claim of unique AI value beyond mature domain controls. UCI and journals additionally use their fuller pre-existing contracts and development-only historical checks.

The principal journal suite omitted explicit numeric guards; native range/equality controls skip nonnumeric strings. Its 8/24 invalid-type/code coverage is therefore a baseline defect. A separate, explicitly post hoc engineering supplement adds the known numeric schema guards and flags all 24 stipulated invalid rows. Primary results are preserved; the correction is functional engineering evidence, not a confirmatory method comparison or AI gain.

## Financial sources and rights

The prior SEC-FinTables development audit and 24 published-output rescoring remain historical evidence. Annotated cells include logical participants, not solely altered cells. The 210 reserved SEC bases were not newly read or scored. The inherited adapter carries explicit coordinates, signs, units and rounding tolerances; four analyst-created development proposals still await independent review. They are not newly model-generated financial discoveries.

The preserved FinRule audit covers 147 files and records a release/paper count discrepancy (1,122 versus 1,117 task variants; cash-flow 323 versus 318), identity issues and logged failures. Given-principle execution is a legitimate conditional task; arbitrary generated-rule semantic validity is a different task. No new FinRule LLM results or repaired gold labels are claimed.

Flights' imputed reference, Tax's historical/normalization assumptions and Rayyan's uncertain accuracy labels prevent their inclusion in the new primary detection claim. Prior optional missingness experiments are preserved, not relabelled as new inference. Give Me Some Credit and BAF access/rights remain optional: no configured Kaggle credentials and unresolved publisher/redistribution conditions respectively. None blocks the five-source local experiment.

UCI source pages establish CC BY 4.0 in the prior rights review. Hospital/Beers are used locally under conditional research benchmark provenance; this repository does not redistribute their raw records or assert unrestricted commercial reuse. The official Qwen model uses Apache 2.0. Actual model inputs comprise public schemas/descriptions and self-authored journal examples, with no UCI/Hospital/Beers rows, private-bank records or personal source records. Exact new responses and prompts are committed because they contain this restricted input class. Generated citations are model output, not verified authority. A downstream university or company deployment must reassess its own data rights.

## Independent semantic evaluation

No human has adjudicated these generated rules. Pending review packets hide selector decisions and model condition; two reviewers must independently mark validity, source applicability and cannot-judge, cite authoritative evidence, and inspect accepted, rejected and abstained candidates. The preserved [review protocol](../final/semantic_adjudication_protocol.md) applies. No agreement coefficient, semantic precision, unjustified-promotion rate or real financial error recall exists yet. Generated-rule output and technical evaluation are real completed evidence; independent meaning remains an external dependency.
