# Final decision

**CONDITIONAL GO:** continue Pilot 2 as a narrowly specified empirical reliability and limitation study. **NO-GO:** claim a new general-purpose qualification method, production-safe automatic rule promotion, an independent semantic-validity result, or a full LeDQeR performance reproduction.

The core model experiment actually ran using free local Qwen inference. The generated rules were technically evaluated and compared through A/B/C/D with development-only selection and held-out entity groups. Hospital provides measured additional reference coverage with a burden/coverage tradeoff. Beers provides a measured zero-increment result above stronger controls, with large extra workload under technical filtering. Exact counts and all controlled-source outcomes are in the [execution summary](execution_summary.md) and machine-readable `results/execution/summary.json`; those files are derived only after the complete bounded generation population exists.

The engineering service can accept real proposals while retaining a separate approval gate. This closes the earlier execution blocker; it does not provide independent semantic ground truth. C remains a deliberately conservative documentary baseline whose abstention and lost coverage must both be counted.

C's known constraints are contained in strong D. Its zero acceptance above that suite follows from entailment and redundancy rejection by construction; weak-suite gains can reintroduce already known controls. This result cannot support a claim that all evidence-based qualifiers lack incremental value. B's measured Hospital tradeoff and A's Beers burden remain empirical fixed-candidate observations.

Hospital's `strong` configuration remains a basic missing-token screen; Beers adds lexical numeric screening only. Hospital B's ZIP/ZIP+4 pattern is conventional and could be implemented without an LLM. Incremental AI value above a mature source-specific business suite is not established by those six reference hits. A fair independent domain baseline is another early thesis gate.

| Gate | Decision |
|---|---|
| Free, real inference and candidate preservation | Achieved locally; no user API key or billed inference required |
| Interpretable same-candidate method comparison | Achieved for the stated controlled/reference tasks; label access differs explicitly |
| General independent semantic rule/violation validity | Not achieved: no human judgments; source/reference labels answer narrower questions |
| Useful novelty versus closest work | Unconfirmed: Bayesian full text unavailable; supervisor must assess the narrower gap |
| Nine-month scope | Plausible if semantic reviewers, source rights and a fresh holdout are secured early |
| Automatic return to Pilot 1 | Rejected as an inference; its stronger-baseline and transfer limitations remain |

Proceed only if the supervisor accepts the narrowed contribution and independent review is feasible. If full closest-work inspection removes the gap, or meaningful semantic labels cannot be obtained, stop this thesis framing instead of accumulating more prompts and infrastructure. The practical artifact remains useful even if the scientific direction is rejected.

Remaining external causes are concrete: unavailable Bayesian full text (HTTP 403); no independent domain reviewers or labels; no real-bank data authorization/integration; no demonstrated fresh-task restore until the environment draft is published and tested. Optional Gemini credentials, Kaggle access and a large-model GPU are not prerequisites for the completed local study. Larger model performance and generalization beyond this portfolio remain unmeasured rather than inferred from model size.
