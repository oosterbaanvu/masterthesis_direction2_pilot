# Dataset qualification and appropriate roles

Authoritative URLs, exact source commits, original/extracted SHA-256 pins, licence statements and expected schemas are in `config/datasets.yaml`. Measured Pilot 2 schemas, row counts, byte hashes and acquisition status are in `results/acquisition.json`. Pilot 1 metadata and contracts were reused with attribution, **not** its experimental results. No raw dataset is committed.

| Source | Pilot 2 qualification | Scientific role and limits |
|---|---|---|
| UCI Credit | QUALIFIED for controlled experiments; no natural DQ gold | 30,000 rows. Customer snapshot, target excluded. Documented and previously observed status codes differ; provisional contract domains are explicitly inherited priors, not newly discovered truth. Negative bill balances can be valid. Duplicate groups remain together. |
| UCI Bank Marketing | QUALIFIED for controlled and delivery monitoring; no natural DQ gold | 41,188 rows. `y` excluded. `unknown` and `pdays=999` are source sentinels, not automatically erroneous. Previous-contact/outcome semantics support limited cross-field checks. The original file has ordered deliveries but no year column; contiguous macro-indicator runs support a descriptive delivery track, not dated customer-level longitudinal truth. |
| UCI White Wine | QUALIFIED for controlled nonfinancial generalization | 4,898 rows; sensory `quality` excluded. Screening ranges and free/total sulfur relation are provisional and subject to measurement uncertainty. No natural DQ labels or temporal sequence. |
| Raha Flights | CONDITIONAL published-reference agreement and workload | 2,376 rows. Natural inter-source conflicts; Pilot 1's upstream investigation found imputed clean-reference values. Here the pinned pair is reacquired and differences rescored, but those airline sources are not independently re-adjudicated. Completeness detects an important subset, not all cross-source truth conflicts. |
| Raha Beers | CONDITIONAL representation/missingness benchmark | 2,410 rows; positional header adapter required. Reference changes mix missing tokens, units, formatting and values. Strict difference agreement is not adjudicated semantic error precision. |
| Raha Tax | CONDITIONAL synthetic/reference-normalization sensitivity and scale | 200,000 rows. Synthetic corruption; clean reference includes dropped ZIP zeros and `0.0` representation changes. The two explicitly normalized columns are rate and ZIP; arbitrary codes are never cast to numbers. Remaining differences are not automatically real errors. |
| Raha Hospital | QUALIFIED as narrow synthetic typo sanity/workload only | 1,000 rows. Predominantly character substitutions according to inherited provenance. Pilot 2 measures 509 pair differences but does not independently verify the original injection process. Not evidence for subtle financial logic. |
| Raha Rayyan | WORKLOAD/ADJUDICATION ONLY | 1,000 bibliographic rows; 948 strict differences. Header, date, missingness and repair interpretation remain uncertain. Accuracy is withheld, not set to zero. |
| Jung Restaurant | CONDITIONAL published synthetic missingness track | 864 rows. Exclude the 30 `class` reference changes from the scored error task; 125 eligible differences remain. Provided row order is the alignment assumption, not independently verified entity resolution. |
| Jung Cars | CONDITIONAL published synthetic missingness track | 406 rows. Of 820 strict differences, 710 are numerically equivalent on explicitly numeric columns; 110 missing differences remain. No indiscriminate normalization of identity/code fields. |
| Feedzai BAF Base | OPTIONAL / BLOCKED; not executed | No Kaggle variable bindings present in this machine, and licence remains unresolved (publisher NC-ND versus prior Kaggle NC-SA metadata). No download attempt bypasses authentication or rights. Pilot 1's former successful acquisition does not grant Pilot 2 credentials. Fraud outcome is not a DQ label. |
| Give Me Some Credit | OPTIONAL / BLOCKED; not executed | No usable Kaggle configuration or rule-acceptance evidence in this machine; competition terms unresolved. No cell-level DQ gold and no acquired file/hash are invented. Default outcome is not a DQ label. |
| SEC-FinTables | CONDITIONAL financial logical-participation task | Three released sets of 1,000 tables; structural audit completed. Annotation, semantic and rights caveats detailed in `benchmark_audit.md`. Suitable for released-output scoring and bounded exploratory logical-location checks; unsuitable as unqualified natural corruption gold. |

TableEG Credit remains **REJECTED as independent gold**: Pilot 1's provenance investigation identifies algorithmic imputations/repairs in the purported clean reference. That prior investigation is cited rather than newly claimed as repeated here. These outputs are not verified natural errors and are not acquired as a replacement for blocked Kaggle data.

Every acquired source receives a working service scan. All ten regular/pair datasets are scanned at full row count, including Tax's 200,000 rows. SEC uses a representative development table in the governance service and all 208 exploratory base IDs per condition in the baseline evaluator. Optional sources have no scan and no imputed performance.

UCI licences are inherited as CC BY 4.0 from the authoritative registry/citations; bank and wine archive documentation were acquired as pinned members. Raha's repository licence does not independently settle all upstream data rights; Jung upstream redistribution remains unconfirmed; SEC has no repository licence. These uncertainties do not become permission to redistribute. Exact dirty/clean values, restricted data, original model outputs and papers stay outside Git.

The deterministic contracts reuse source documentation and pre-existing Pilot 1 metadata. Some provisional domains were originally observed on the entire public source. Consequently this is an existing-control operational setting, **not a claim that all baseline knowledge was first learned exclusively from Pilot 2 development rows**. New statistical envelopes and replacement sampling use development rows only; prediction targets, evaluation labels and reference repairs do not configure detectors. Generalization to an entirely unseen source must be tested separately.
